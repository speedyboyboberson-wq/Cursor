# Agents

This repo is the **Alvarado Concrete LLC** site (Columbia Heights / Twin Cities, MN). The GitHub remote may still be named `Cursor`.

Before building another local-business website from this account:

1. Read `WEBSITE-PLAYBOOK.md`.
2. Reuse this site’s IA (home, services, quote, about, gallery, hours, contact dropdown, live URL).
3. Change the visual system to match the new shop. Do not copy Alvarado’s charcoal/rust flatwork onto a different kind of place.
4. Prefer a new GitHub repo named after that business so each site stays distinct.
