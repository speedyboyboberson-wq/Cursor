# Agents

This repo is the **3 Corner Restaurant Bar Liquor & Grill** site (New Brunswick, NJ). The GitHub remote may still be named `Cursor` until the owner renames it to `3-corner-restaurant`.

Before building another restaurant website from this account:

1. Read `WEBSITE-PLAYBOOK.md`.
2. Reuse this site’s IA (home, menu, about, gallery, hours, delivery dropdown, live URL).
3. Change the visual system to match the new room. Do not copy 3 Corner’s black/gold salon onto a different kind of place.
4. Prefer a new GitHub repo named after that restaurant so each site stays distinct.
