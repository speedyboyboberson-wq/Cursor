# King of Gyro

Public website for **King of Gyro**, the halal gyro shop at 105 Easton Ave, New Brunswick, NJ.

## Live site

**https://wily-valley-440.harvis.page/**

- Phone: (732) 964-3400
- Menu, hours, map, gallery, and delivery dropdown (DoorDash, Uber Eats, Grubhub)

To republish after edits:

```bash
./scripts/deploy.sh
```

GitHub Pages (optional, after enabling Actions as the Pages source): https://speedyboyboberson-wq.github.io/Cursor/

## Local preview

```bash
python3 -m http.server 8080
```

Then open http://127.0.0.1:8080/

## Pages

- `index.html` — home
- `menu.html` — full menu
- `about.html` — Easton Ave story
- `gallery.html` — photos from Yelp, DoorDash, and Restaurantji
- `contact.html` — hours, map, contact form
