# King of Gyro

Public website for **King of Gyro**, the halal gyro shop at 105 Easton Ave, New Brunswick, NJ.

## Live site

**https://brewpage.app/kingofgyro/Bvq03r7QSl/index.html**

Open that exact link (including `index.html`). It is a working public HTTPS page: menu, hours, gallery, and delivery links. Google Safe Browsing does not list it as unsafe.

- Phone: (732) 964-3400
- Menu, hours, map, gallery, and delivery dropdown (DoorDash, Uber Eats, Grubhub)

## Local preview

```bash
python3 -m http.server 8080
```

Then open http://127.0.0.1:8080/

## Pages

- `index.html` — home
- `menu.html` — full menu
- `about.html` — Easton Ave story
- `gallery.html` — photos from Yelp, DoorDash, and Restaurantji
- `contact.html` — hours, map, contact form
